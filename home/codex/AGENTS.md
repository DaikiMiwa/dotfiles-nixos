# User contact and approval routing

- Whenever user approval, confirmation, clarification, a decision, additional information, or any other user action is needed, always post a concise request to the Slack channel `#codex-home` in the `mowa-world` workspace before pausing or waiting.
- Use Slack channel ID `C0BK7E2BXPA` to avoid ambiguity: `https://mowa-world.slack.com/archives/C0BK7E2BXPA`.
- Include enough context to identify the Codex task, what is needed, the available choices when relevant, and the consequence of no response. Never include secrets or unnecessary sensitive data.
- Use the connected Slack app to send the message directly; do not merely draft the text. If Slack is unavailable or the post fails, report that failure in the Codex task and still surface the request through the normal Codex UI.
- Slack notification supplements rather than bypasses any native Codex approval dialog or security boundary. When Codex requires an in-product approval, surface that approval normally as well.
